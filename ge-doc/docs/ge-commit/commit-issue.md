# Issue key in commits

When an issue tracker is configured for the repository (**Repository → Project Settings → Integrations**), the commit dialog includes an **Issue** picker.
Checking **Include issue key** prefixes the message with the ticket id, for example:

```text
PAY-123 Fix payment timeout in payment service
```

See [Issue tracker](../ge-integrations/issue-tracker.md) for Jira or Linear setup, branch naming, and comments.
